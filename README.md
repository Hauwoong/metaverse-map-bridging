# Generative Map Bridging — 끝점 조건 영상 생성으로 실사 3DGS 조각 맵 잇기

메타버스컴퓨팅 기말고사 대체 프로젝트 (국민대학교, 2026-2학기)

실사 촬영으로 만든 두 개의 3D Gaussian Splatting 장면 A, B 사이에 **촬영되지 않은 공간**을 끝점 조건 영상 생성(LTX-Video)으로 만들고, 그 영상을 3D 로 복원·정렬·이음새 최적화해 하나의 장면으로 잇는다. A→B 를 한 번에 촬영한 뒤 중간 구간을 숨겨 **정답(GT)으로 정량 평가**한다.

```
촬영(A→중간→B) → COLMAP 공통 좌표계 → A·B·GT 3DGS (splatfacto)
   → A 출구 / B 입구 렌더 → 끝점 조건 생성 (LTX-Video)
   → 생성 영상 SfM → Sim(3) 정렬 → 연결 구간 3DGS + 이음새 최적화 → 병합 플라이스루
```

## 참고
- 촬영 원본 영상(`*.MOV`)과 3DGS 체크포인트는 용량 문제로 포함하지 않는다.
- 일부 스크립트는 작성 환경의 절대 경로(`/mnt/c/Users/.../메타버스_기말프로젝트`, `/home/.../data`)를 쓴다. 다른 환경에서는 경로 변수를 바꿔서 실행한다.
- 과제 공지문(강의 자료)은 포함하지 않는다.
